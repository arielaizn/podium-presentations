# Six useful companion documents

Select six genuinely different jobs for the audience. Describe each document's outcome before writing it. A useful default mix is:

1. Readiness or execution checklist: prioritized, checkable actions with a clear completion standard.
2. Step-by-step guide: prerequisites, ordered actions, expected results and recovery steps.
3. Worksheet or planning workbook: fillable prompts, decision fields and an example of a good answer.
4. Decision rubric: criteria, weights or trade-offs, a worked example and how to interpret a result.
5. Template or script pack: ready-to-adapt materials with instructions and placeholders clearly marked.
6. Troubleshooting/FAQ or action plan: topic-specific failure signs and remedies, or milestones, owners and measures.

Choose a better mix for the topic. For teaching, use exercises, answer key, practice plan, quick reference, assessment rubric and project guide. For a product pitch, use buying checklist, rollout guide, evaluation rubric, procurement FAQ, stakeholder worksheet and adoption plan. Avoid making legal, financial, health or operational promises unsupported by sources.

Each PDF must add an actionable capability beyond the slide deck. Usually 2–6 focused pages is enough; length is not the goal. Never pad, repeat six slight variations, or turn each slide into a separate bonus. At least six separate PDF files are mandatory unless the user changes the request.

Use the deck's language and brand. For Hebrew, shape RTL text correctly using a capable renderer; do not simply reverse Unicode characters. Preserve English terms, symbols and numbers. Include clear headings, page numbers, adequate margins, readable fonts and provenance for factual claims. Render every page and inspect for clipping, broken glyphs, orphan headings and misleading checkboxes. Check extracted text as a supplement, not as a substitute for visual inspection.
