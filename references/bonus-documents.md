# Bonus planning
Choose six distinct documents for the actual presentation. Each should state its purpose, who uses it, prerequisites, concrete steps or checks, an example and a next action. Scale length to usefulness, generally 2-6 pages; do not inflate a simple checklist.

For training: readiness checklist, setup walkthrough, practice workbook, reusable prompt/templates guide, troubleshooting guide, 30-day implementation plan.
For sales: buyer evaluation checklist, implementation guide, ROI worksheet with stated assumptions, questions for stakeholders, adoption plan, FAQ/objection guide.
For strategy: decision checklist, execution roadmap, risk register worksheet, KPI definition guide, responsibility template, meeting facilitation guide.
Adapt these instead of blindly copying the categories. Cite external facts when needed. Use placeholders clearly for information the user has not supplied. Do not invent prices, guarantees or client evidence.
