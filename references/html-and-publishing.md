# HTML and publication
Use semantic slide sections, native text, readable HTML tables/charts, locally bundled media and brand fonts. Animate titles and content in reading order with staggered entrances and a coherent set of slide transitions (fade/slide/scale). Respect prefers-reduced-motion; hide nonactive slides from assistive technology; give navigation controls accessible names and provide focus indicators. Offer arrow keys, Home/End, swipe, slide count, fullscreen and a print stylesheet showing every slide.

Use one canonical content source and check content parity against PPTX/PDF. The included exporter covers text content only: manually adapt complex tables, charts, video, image galleries and any extra fields instead of silently dropping them. Avoid CDN-only dependencies and external fonts when an offline version is requested.

Publish the static folder with an available verified Vercel account/project, or a supported Here.now capability. Read applicable hosting skills. Never assume authentication exists. Do not change existing product deployments to host an unrelated presentation. Verify the resolved owner/project before a mutation. Check the returned live URL and navigation/asset loading after publication. If neither host is usable, deliver local files and name the concrete blocker; do not substitute a different host without the user's instruction.
